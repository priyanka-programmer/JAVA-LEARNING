
# Linear Search in Java

This folder contains my practice programs while learning **Linear Search** in Java. These programs helped me understand how to search for elements in arrays, strings, and specific ranges, along with solving beginner-level search-based problems.

## 📂 Files Included

- `LinearSearch.java` – Basic linear search in an array (returns index if found)
- `SearchInString.java` – Search for a character in a string
- `SearchInRange.java` – Search for an element within a given range of an array
- `FindMin.java` – Find the minimum element in an array
- `CountEven.java` – Count numbers with an even number of digits in an array

## 📚 Concepts Learned

- What is Linear Search
- Time Complexity: **O(n)**
- Searching in arrays
- Searching in strings
- Searching within a specific range
- Finding the minimum element in an array
- Using helper methods to solve problems
- Traversing arrays using loops

## 🚀 Learning Outcome

Through these programs, I learned how linear search works, when to use it, and how to solve beginner-level searching problems using Java.
