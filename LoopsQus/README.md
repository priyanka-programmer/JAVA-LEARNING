# Loop Questions in Java

This folder contains my Java practice programs based on loops. These problems helped me improve my understanding of `for`, `while`, and `do-while` loops, along with number-based logic and pattern recognition.

## 📂 Files Included

- `Counting.java` – Print numbers using loops
- `CountDigits.java` – Count the number of digits in a number
- `Reverse.java` – Reverse a given number
- `Palindrome.java` – Check whether a number is a palindrome
- `Armstrong.java` – Check whether a number is an Armstrong number
- `Sum_of_digit.java` – Find the sum of digits of a number
- `Five_count.java` – Count the occurrence of digit 5 in a number
- `Fibono.java` – Print Fibonacci series
- `fiboseries.java` – Another implementation of the Fibonacci series

## 📚 Concepts Learned

- `for`, `while`, and `do-while` loops
- Loop control and iteration
- Number manipulation
- Counting digits
- Reversing numbers
- Palindrome checking
- Armstrong number logic
- Fibonacci sequence
- Sum of digits
- Frequency of a digit in a number

## 🚀 Learning Outcome

By solving these problems, I strengthened my understanding of loops, conditional statements, and basic algorithmic thinking in Java. These programs form the foundation for solving more advanced DSA problems.
